# Rastreador_Onibus_BH
Aplicação WEB que rastreia a localização dos ônibus de Belo Horizonte em tempo real, nas suas respectivas linhas.

Funcionalidades de cada Membro do grupo:

CODAMA + GABRIEL FERNANDES:

- HTML
- UTILIZAÇÃO DA API PBH
- Tratar os dados

BRAGA + JOAOZINHO:

- Implementar o estado inicial
- Mostram o mapa de BH com todos os onibus ativos
- Filtros de RAIO
- Mudança da sua localização(sua localização real ou a que o usuário mandar)

BRANCO + CODAMA:

- Selecionar as linhas(filtro de linhas)
- Mostrar os pontos de onibus da linha
- Mostrar a localização dos onibus da linha em tempo real
- Mostrar o ponto mais próximo do usuário e daqui quanto tempo  o onibus 
- Ao selecionar o ponto, mostrar os horários do onibus

MATEUS:

- Front-end
- css
